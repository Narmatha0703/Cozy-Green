 🌿 CozyGreen

CozyGreen is a sleek and minimal plant shopping web app made with pure HTML & CSS. It's green, it's clean, and it’s made for plant lovers who appreciate calm vibes and good design.

 ✨ Highlights

- 🍃 Nature-inspired, responsive UI
- 🪴 Plant listings with clean cards & pricing
- 🎨 Soft color palette to soothe your screen time
- ⚡ Zero dependencies — just open and go


 🚀 Quick Start

1. Clone the repo  
   `git clone https://github.com/your-username/cozygreen.git`

2. Open `index.html` in your browser  
   That’s it. No setup, no stress.
